# Neue Inventur (`?p=inventur_neu`, nur Admin)
Felder:
- Name und Stichtag
- Lager 1 oder Lager 2 (mit Kunde)
- Warenarten (Rohstoffe, Bulk, Verpackung, Etiketten, Fertigware, Verbrauchsgüter)
- Plätze und Kisten. Ohne Auswahl wird das ganze Lager gezählt, Plätze kommen dann beim Scannen dazu.
- Zähler
- Nachzählen durch eine zweite Person ab x %
- Toleranzen
- Grenzen für „kleine Differenzen übernehmen“

Plätze, die schon in einer offenen Inventur sind, sind gesperrt. So sind mehrere Teil-Inventuren nacheinander möglich.

# buchen.php — Kontoauszug buchen

`?p=buchen`: CSV hochladen oder einfügen -> Spalten zuordnen (Vorschau, Auto-Erkennung, anpassbar) ->
Importieren. Danach je Import zwei Reiter: Eingang (Kundenzahlungen -> offene Debitoren-Rechnungen) und
Ausgang (unsere Zahlungen -> offene Eingangsrechnungen). Pro Zeile ein Vorschlag (bestes Match
vorselektiert), Dropdown mit allen offenen Rechnungen, „Zuordnen & buchen" bucht alle ausgewählten Zeilen,
Haken „Ignorieren" markiert Zeilen als erledigt. Gebuchte/ignorierte Zeilen stehen unter „Erledigt".
Bisherige Importe unten; „Entfernen" löscht nur die noch nicht gebuchten Posten eines Imports.
